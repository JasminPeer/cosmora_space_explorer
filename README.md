## ⚙️ Prerequisites & Setup

### Requirements
- Basic familiarity with `HTML`
- Git installed on your local machine

### Installation Steps
```bash
git clone https://github.com/JasminPeer/cosmora_space_explorer.git
cd cosmora_space_explorer
# Open index.html directly in your web browser or use VS Code Live Server
```

---

## 🚀 How to Use
Double-click `index.html` or serve via `npx serve .` to experience the space explorer portal.
